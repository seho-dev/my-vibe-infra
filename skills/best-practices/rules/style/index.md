# Style Rules Index

`style/` groups the coding-basics rules and their related sub-rules.

## Read Order

1. Read [coding-basics.md](coding-basics.md) before writing code.
2. Read the matching specialized rule when the change touches normalize or fallback.
3. Read [../css.md](../css.md) when the change touches CSS or styles.
