# General Documentation Rules

Applies to ALL document types.

## Language

- English for content

## Structure

- Max 3 heading levels: `#` > `##` > `###`
- Code blocks must specify language: ` ```markdown `, ` ```js `, etc.
- Tables use `:---` alignment
- Links use relative paths

## Writing Style

1. **No fluff** - Avoid "This document aims to...", "Next we will..." style filler
2. **Tables first** - Use tables for structured data, not lists
3. **Concrete examples** - Conventions must have good/bad example comparisons
4. **Concise** - Use minimal language to convey information, remove redundant descriptions

## Quality Checklist

- [ ] Heading levels reasonable?
- [ ] Code blocks specify language?
- [ ] Tables aligned?
- [ ] Links valid?
- [ ] English language used?
- [ ] Concise enough?
